# FreeKate

Модифицированный клиент [Kate Mobile](https://katemobile.ru) для работы с [OpenVK](https://github.com/openvk/openvk). Основан на версии 81.

> [!WARNING]
> Содержит вайбкод, прошедший проверку человеком

## Функциональность

* Вырезан трекинг и рекламные сети (Flurry, myTarget, Google Advertising ID, пиксели рекламных постов)
* Добавлена возможность выбирать инстанс
* При переключении аккаунтов инстанс сохраняется между аккаунтами, у каждого инстанса своя база
* Ссылки внутри приложения ведут на ваш инстанс, домены-зеркала подтягиваются через `Ovk.getMirrors`
* Скрытие NSFW постов (настраивается в самом OpenVK в Настройках -> Интерфейс)
* Скрыты кнопки «Истории» — в OpenVK их нет

## Установка

* На трубках с Android 12 и ниже: просто устанавливается APK
* На Android 13 и выше:
* * Через компьютер по ADB с параметром --bypass-low-target-sdk-block
* * Через Install with Options и Shizuku

Имя пакета — `cc.veselcraft.freekate`, так что FreeKate ставится рядом с настоящим Kate Mobile и не конфликтует с ним.

## С точки зрения пользователя

На экране входа есть поле для ввода домена инстанса и галочки "включить HTTPS".

Если вы зарегистрированы на openvk.org, то менять ничего не надо — просто введите свой логин и пароль.

Если зарегистрированы на другом сайте на движке OpenVK, то туда стоит ввести домен того сайта, либо обратиться к администратору за настройкой.

Если вы тестируете OpenVK в своей локальной сети, то думаю, вам и объяснять ничего не надо — просто вводите айпишник и отключаете галочкой HTTPS.
